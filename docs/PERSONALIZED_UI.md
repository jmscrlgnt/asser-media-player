# Personalized UI notes

This build is intentionally personal rather than release-ready. The right side is a **Now Playing** information panel instead of a queue. Artwork is assigned per local media item by double-clicking the artwork area while a track is playing.

The playback queue still exists internally for Previous, Next, Shuffle, Repeat, and Play Next behavior.

The mute control is custom-drawn and synchronized with the volume slider: mute displays 0%, while unmute restores the previous volume.
