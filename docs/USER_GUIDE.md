# User Guide

## Add media

Use **+ Add files** to select one or more files, **Add folder** to recursively scan a directory, or drag files/folders onto the application window.

Duplicate paths are ignored. Unsupported files are skipped.

## Browse the library

The left navigation provides All media, Music, Videos, Favorites, Recently played, and user-created playlists. Search filters the current view. The Sort menu can order the visible library by title, recency, play count, or date added.

Double-click a library row to play it. Right-click for Play now, Play next, Add to queue, favorite, playlist, file-location, copy-path, and remove-from-library actions.

## Queue

The **Up next** panel shows the active queue. Double-click an entry to play it. Use the arrow buttons to reorder the queue, Remove to remove one entry, and Clear to empty it.

## Playback

The bottom player bar contains seek progress, previous/play/stop/next, shuffle, repeat, volume, mute, speed, and full-screen controls.

Repeat cycles through Off → All → One. Playback speed supports 0.75x, 1.0x, 1.25x, 1.5x, and 2.0x.

## Missing files

AsserPlayer stores file paths, not copies of media. If a file is moved or deleted outside the application, it appears as **Missing**. Use **Clean missing** to remove stale entries. This never deletes files from disk.

## Full screen

Press F11, use the Full screen button, or double-click the media stage. The normal navigation, queue, library, and title bar collapse so the media stage can use the available screen. Press Esc to leave full screen.

## Starter artist playlists

v2.1 creates personal playlist templates for the configured starter artists. They do not contain bundled commercial recordings. Import local files you legally own; tracks whose filename/path contains an artist name are automatically added to the matching playlist and to `Asser Mix`.

For best automatic organization, use filenames such as:

```text
Artist - Track Title.mp3
```

The audio stage will show the parsed track title and artist when this format is used.
